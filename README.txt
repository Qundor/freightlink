FREIGHTLINK PREMIUM OFFLINE — VERSION 1

This version does NOT require Live Server, XAMPP, PHP, Node.js or a database.

Open:
1. Extract the ZIP.
2. Double-click index.html.
3. The website opens directly in your browser.

IMPORTANT:
The hero photograph is loaded from Unsplash, so an internet connection is needed for that one remote image. Everything else — HTML, CSS and JavaScript — is local.
The contact form is a front-end demo and does not send messages yet.
